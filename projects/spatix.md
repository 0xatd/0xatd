# Spatix

**Hosted service retired · source code public**

[Source repository](https://github.com/0xatd/spatix) · [Python MCP package](https://pypi.org/project/spatix-mcp/)

## The product

A geospatial tool for turning files and structured location data into maps that people and agents can work with.

## What I built

- A Next.js/MapLibre interface for map creation and viewing.
- FastAPI/GeoPandas processing for uploaded geospatial data.
- API routes for programmatic map workflows.
- A Python MCP server and agent skill alongside the application.

I retired the hosted service to reduce ongoing infrastructure and maintenance costs. The source and package remain as a record of the build. Old domains and hosted API examples are not maintained demos; installing the MCP package alone does not restore the retired backend. The README retains the architecture and setup material for inspection or adaptation.
